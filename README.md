# Personal Portfolio

Welcome to my personal portfolio repository! This repository contains the source code for my main portfolio website along with several mini-projects that showcase my skills in frontend web development.

## 🚀 Live Demo
[View Live Portfolio](https://aseesmakkar45.github.io/PORTFOLIO/)

## 📂 Projects Included

1. **Main Portfolio**: A responsive portfolio showcasing my education, skills, and contact information.
2. **Profile Card Component** (`/projects/profile-card`): A visually catchy profile card reflecting personal and educational info.
3. **Survey Form** (`/projects/survey-form`): A clean and accessible survey form interface.
4. **Portfolio Mini-Site** (`/projects/portfolio-website`): An alternative personal website layout.

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox, CSS Animations, Responsive Design)
- Vanilla JavaScript

I'm a Computer Science Engineering student passionate about web development, programming, and creating visually appealing user interfaces. I enjoy learning new technologies and building projects that solve real-world problems.

## 📝 Setup Instructions
To view this project locally:
1. Clone the repository: `git clone https://github.com/aseesmakkar45/PORTFOLIO.git`
2. Open `index.html` in your favorite web browser. No local server is required!
